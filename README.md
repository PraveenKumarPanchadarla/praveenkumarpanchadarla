## 🚀 Featured Project

### NYC Taxi Data Engineering Project · Azure

An end-to-end Azure data pipeline that processes NYC Taxi trip data from raw files into curated datasets for downstream analytics.

**Architecture & technologies**

`Source Files` → `Azure Data Factory` → `ADLS Gen2 (Bronze)` → `Azure Databricks / PySpark` → `Delta Lake (Silver & Gold)` → `Analytics`

**What I implemented**
- Built an end-to-end ingestion and transformation workflow using Azure Data Factory, ADLS Gen2, Azure Databricks, PySpark, and Delta Lake.
- Configured dynamic file and folder-based ingestion to detect and process incoming source files without manual file selection.
- Organized the lakehouse into Bronze, Silver, and Gold layers.
- Developed PySpark transformations to cleanse, filter, transform, and enrich trip data.
- Performed validation at each layer before promoting data to the next stage.
- Prepared curated datasets for downstream analytics and business reporting.
